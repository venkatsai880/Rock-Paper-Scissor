# Rock Paper Scissors Game

An interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Live Demo

[Play Rock Paper Scissors](https://venkatsai880.github.io/Rock-Paper-Scissor/)

## Preview

![Rock Paper Scissors Game](screenshots/game-preview.png)

## Features

- Interactive Rock, Paper, and Scissors gameplay
- Computer generates a random choice
- Real-time score tracking
- Win, lose, and draw detection
- Interactive hover effects
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
